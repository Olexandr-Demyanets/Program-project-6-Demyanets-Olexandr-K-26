# Програмний проєкт 6 — варіант 16

Сопрограма, що читає зі стандартного входу дійсні числа і повертає середнє арифметичне трьох останніх.
Нулі у середньому не враховуються: на нулі сопрограма зупиняється і не дозволяє себе відновити,
доки не мине 1 с. Сопрограма при цьому не блокується і не засинає.

## Вимоги

- компілятор з підтримкою C++20 (перевірено на g++ 15.2.0, MSYS2 UCRT64);
- CMake 3.20+.

## Збирання

З папки проєкту:

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
```

Без CMake:

```powershell
g++ -std=c++20 -O2 -Wall -Wextra -Wpedantic -static src/main.cpp src/console_report.cpp src/mean_coroutine.cpp -o mean3_demo.exe
```

## Запуск

З файлу (у PowerShell через `cmd /c`, бо в ньому немає оператора `<`):

```powershell
cmd /c "build\mean3_demo.exe < input\02_zero_pauses.txt"
```

З клавіатури — числа через пробіл або Enter, завершення вводу Ctrl+Z, потім Enter:

```powershell
build\mean3_demo.exe
```

Необов'язковий аргумент — як часто демо пробує відновити сопрограму після нуля, мс (10–5000, типово 300):

```powershell
cmd /c "build\mean3_demo.exe 500 < input\02_zero_pauses.txt"
```

Тести:

```powershell
ctest --test-dir build --output-on-failure
```

## Формат вхідних даних

- числа розділяються пробілами, табуляціями або переведенням рядка;
- десятковий роздільник — крапка: `12`, `-3.5`, `+7`, `.5`, `2.5e1`;
- `0` (а також `-0.0`, `0e5`) — зупинка на 1 с, у середнє не входить;
- від `#` до кінця рядка — коментар;
- некоректні значення (`abc`, `3,5`, `1e999`, `inf`) пропускаються з повідомленням.

## Що виводить програма

Для `input\05_too_few.txt` (`4.2 0 8.4`):

```text
 рядок │ число        │ три останні числа                 │ середнє
───────┼──────────────┼───────────────────────────────────┼─────────────────────
     2 │ 4.2          │ [4.2]                             │ — (1 з 3)
     2 │ 0            │ НУЛЬ: не враховано, сопрограму зупинено; середнє — (1 з 3)
       │   ✗ спроба 1 через    0 мс після нуля: ВІДМОВА, ще 1000 мс
       │   ✗ спроба 2 через  317 мс після нуля: ВІДМОВА, ще  683 мс
       │   ✗ спроба 3 через  631 мс після нуля: ВІДМОВА, ще  369 мс
       │   ✗ спроба 4 через  941 мс після нуля: ВІДМОВА, ще   59 мс
       │   ✓ спроба 5 через 1255 мс після нуля: сопрограму відновлено
     2 │ 8.4          │ [4.2, 8.4]                        │ — (2 з 3)
────────────────────────────────────────────────────────────────────────────────
 Прийнято чисел: 2 · нулів (зупинок): 1 · помилок у вхідних даних: 0
 Відхилено передчасних спроб відновлення: 4
 Середнє не обчислено: прийнято менше трьох ненульових чисел.
```

Кожне число дає рядок із трьома останніми числами та їхнім середнім (`—`, поки чисел менше трьох).
Після нуля видно кожну спробу відновлення: до 1 с — відмова, після — сопрограма продовжує роботу.
Мілісекунди у спробах відрізняються між запусками.

## Як це працює

- `meanOfLastThree` — сопрограма-генератор: кожне відновлення читає один токен і через `co_yield`
  видає подію `MeanUpdate`, `ZeroPause` або `InputError`.
- На `ZeroPause` об'єкт обіцянки (`promise_type`) запам'ятовує момент «не раніше ніж» = час нуля + 1 с.
- Відновити сопрограму можна лише через `MeanCoroutine::resume()`; якщо час не минув, він одразу
  повертає `Refused` і залишок часу, не торкаючись сопрограми.
- Чекає лише викликач (`main`): після відмови він пробує знову через заданий інтервал.

## Файли

- `src/mean_coroutine.h`, `src/mean_coroutine.cpp` — сопрограма, розбір чисел, вікно з трьох чисел, читання входу;
- `src/console_report.h`, `src/console_report.cpp` — табличний вивід, UTF-8 у консолі Windows;
- `src/main.cpp` — демонстрація роботи сопрограми;
- `tests/tests.cpp` — автотести;
- `input/*.txt` — приклади вхідних даних;
- `CMakeLists.txt` — збирання.
