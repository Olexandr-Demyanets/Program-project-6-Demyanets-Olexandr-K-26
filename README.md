# Середнє трьох останніх чисел

Програма читає дійсні числа зі стандартного входу і після кожного числа показує середнє арифметичне трьох останніх.
Нуль у середньому не враховується, а зупиняє обробку щонайменше на 1 секунду.

## Збірка

```
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

## Запуск

```
build\mean3_demo.exe [інтервал_мс]
```

`інтервал_мс` (необов'язковий) — як часто програма пробує продовжити роботу після нуля:
ціле число від 10 до 5000, типово 300. Довідка: `build\mean3_demo.exe --help`.

**З файлу** (у PowerShell через `cmd /c`):

```
cmd /c "build\mean3_demo.exe < input\02_zero_pauses.txt"
```

## Формат вхідних даних

- Числа розділяються пробілами, табуляціями або переведенням рядка.
- Десятковий роздільник — крапка: `12`, `-3.5`, `+7`, `.5`, `2.5e1`.
- `0` (а також `-0.0`, `0e5`) — зупинка на 1 с, у середнє не входить.
- Від `#` до кінця рядка — коментар.
- Некоректні значення (`abc`, `3,5`, `1e999`, `inf`) пропускаються з повідомленням.

```
# приклад
1.5 2 4
0
-3
```

Готові приклади лежать у папці `input/`.

## Тести
